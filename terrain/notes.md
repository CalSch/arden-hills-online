
# terrain thingy

- arden hills is big
- we need to make a 3d model of it, so we use a heightmap
- we dont want to store the heightmap in git, so we need a way to download & manipulate it
- all the modifications to the heightmap or resulting model need to be reproducible
- so the heightmap comes from a survey called "Statewide Seamless 0.5m Lidar DEM, Minnesota, 2nd Generation"
    - explore here: https://gis.data.mn.gov/datasets/statewide-seamless-0-5m-lidar-dem-minnesota-2nd-generation-/explore
    - more info here: https://mn.gov/mngeo/gis-data-and-maps/info-by-topic/elevation/lidar/lidar-gen2.jsp
- there's a link to a `.vrt` file
    - info about vrt files: https://gdal.org/en/stable/drivers/raster/vrt.html
- then we need to download the data and demosaic it into a TIFF file
- to do this we use `gdal_translate` and give it the geo-coords of the bounding box
    - geo-coords are in the "EPSG:4326" coordinate system
        - basically just lat & long in degrees (-180/-90 to 180/90)
        - info: https://epsg.io/4326
    - on arch, `gdal_translate` comes from the `extra/gdal` package
    - see the `sota.vrt` section in the makefile to see what the command is
